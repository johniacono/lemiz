# Les Misérables

A web app for reading *Les Misérables* in French, with English translations and a dictionary.

Read it at https://johniacono.github.io/lemiz/

## Credits

- Text: Victor Hugo, from [Project Gutenberg](https://www.gutenberg.org/) (public domain).
- Dictionary: derived from [Wiktionary](https://www.wiktionary.org/) via [kaikki.org](https://kaikki.org/), available under [CC BY-SA](https://creativecommons.org/licenses/by-sa/4.0/).
- Translations: machine-translated offline with Opus-MT (fr-en).

See `tools/README.md` for how the data is built.
